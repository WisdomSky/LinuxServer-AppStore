# Pelorus

Pelorus is the AI agent interface built into Selkies. It describes the desktop to an LLM as text, the windows the Selkies window manager places and the controls applications expose over the Linux accessibility tree (AT-SPI), and drives it with mouse, keyboard, window and screenshot actions from a chat. This image runs Pelorus on the Selkies desktop with a split pane web interface.

---

**WebUI Port:** `3000`
